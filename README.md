# 今天不加班

一款复古像素潜行解谜网页游戏：既可以扮演员工拿卡开溜，也可以扮演老板调度巡逻。包含全员同图的每日挑战、五关员工训练和五关老板巡查。

**在线试玩：** [https://shuaitang04-eng.github.io/no-overtime-game/](https://shuaitang04-eng.github.io/no-overtime-game/)

## 三种模式

- **每日挑战：** 每天 00:00（北京时间）生成一张全员相同的 10×8 办公室地图；当天可无限重试，并在浏览器本地记录最佳回合和连续通关天数。
- **员工闯关：** 5 张手工设计关卡依次引入基础移动、隔断遮挡、清洁车封路、临时会议掉头和停电视野；通关后解锁下一关。
- **老板模式：** 调度老板“继续巡逻 / 停留 / 掉头”，阻止确定性员工 AI 拿卡逃生；5 张全新地图独立依次解锁。

页面每次打开仍默认进入每日挑战；切换模式不会丢失当前页面中尚未完成的局面。

## 员工玩法

- 使用方向键、WASD、空格，或触屏点按/方向键移动和等待。
- 先拿黄色门禁卡，再到紫色电梯；红色区域是老板当前视野，金色框是下一步位置与视野。
- 第一次被发现会回到工位、丢失门禁卡并增加怀疑；第二次被发现或 30 回合耗尽即失败。
- 临时会议、停电和清洁车封路都会提前一回合预告。

## 老板玩法

- 每回合选择继续巡逻、停留或掉头；员工会同时行动，并且不会读取你本回合的指令。
- 地图会显示当前视野、完整巡逻路线、继续/掉头落点，以及员工正在前往的门禁卡区或电梯区，但不会泄露员工下一步。
- 同格、交叉换位或员工进入结算后的视野都算抓到；第一次抓到会让员工回工位并丢卡，第二次抓到或拖满 30 回合即获胜。
- 每关只有 2 次停留和 2 次掉头，掉头后冷却 2 回合；糟糕的调度会让员工成功逃进电梯。

## 本地开发

需要 Node.js 24（或兼容当前 Vite 的 Node.js LTS）和 npm。

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run check       # TypeScript + Vitest
npm run test:e2e    # Playwright 桌面/手机浏览器测试
npm run build       # 生产构建到 dist/
npm run preview     # 本地预览生产构建
```

## 实现说明

- **技术：** TypeScript、HTML Canvas、Vite；无运行时框架、后端、账号或网络 API。
- **每日一致：** `Asia/Shanghai` 日期与规则版本经固定哈希和 PRNG 生成关卡；地图、门禁卡、巡逻及事件顺序均可复现。
- **可解验证：** 状态空间求解器会拒绝无解、无需门禁卡或过短的候选；测试批量覆盖完整闰年日期。
- **员工闯关：** 五关使用固定地图、巡逻和事件定义，并由同一状态空间求解器验证可在 30 回合内零暴露通关。
- **老板闯关：** 五张独立地图使用确定性谨慎员工 AI；求解器同时验证每关存在两次抓捕方案，也存在因糟糕调度而让员工逃脱的方案。
- **本地数据：** 教程、静音、每日最佳、连续天数、员工进度和老板进度保存在 v3 `localStorage` 中；v1/v2 存档会自动迁移，损坏数据会安全回退。
- **像素与声音：** 16×16 逻辑像素的原创代码绘制素材，整数倍最近邻缩放；Web Audio 合成四类短音效，无外部素材许可证依赖。
